### Person-Fit Statistics as a Black-Box Detector for LLM Sandbagging

Sandbagging is a class of deceptive behavior in which LLMs deliberately
underperform on an evaluation. This is a concern in pre-deployment
testing for frontier models, as misaligned models may underperform selectively
on items or benchmarks intended to test for hazardous behavior, preventing model
developers from adequately mitigating these behaviors. We treat sandbagging as a
classical psychometric *person-fit* problem and ask whether person-fit statistics
can detect it on hazardous-capability benchmarks.
